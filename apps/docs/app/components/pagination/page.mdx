# Pagination

Corta lista longa. Filtro continua acima; a página fica embaixo da tabela.

## Quando usar

Mais de uma tela de linhas. Uma página só: mostre o resumo, esconda os botões.

<DoDont
  do="Resumo '1–8 de 20' + Anterior/Próxima. Página atual com aria-current."
  dont="Paginar o conjunto já filtrado de outro jeito, ou resetar o filtro ao mudar de página."
/>
