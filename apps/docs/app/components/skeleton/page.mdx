# Skeleton

Placeholder do layout enquanto a lista carrega. Não é um spinner no centro da página.

## Quando usar

Primeira carga de tabela ou card. O contêiner fica `aria-busy`. O osso em si é decorativo.

<DoDont
  do="Repetir a grade real: mesmas colunas, mesma altura de linha."
  dont="Skeleton eterno. Se falhou, vá para ErrorState."
/>
