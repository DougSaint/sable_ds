# EmptyState

Lista vazia e falha de carga são componentes diferentes. Vazio pede o próximo passo. Erro pede tentar de novo.

## Quando usar

Filtro sem resultado, primeira visita, ou a API caiu. Não misture os dois no mesmo card.
