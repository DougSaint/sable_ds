# Breadcrumb

Onde o operador está. Não substitui a nav lateral.

## Quando usar

App Shell e páginas com dois ou três níveis. O último item é a página atual, sem link.

<DoDont
  do="Operação / Pedidos. Página atual com aria-current."
  dont="Repetir o menu inteiro no breadcrumb, ou linkar o último item."
/>
