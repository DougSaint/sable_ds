# SelectionBar

Ações em lote. Só existe enquanto há linhas marcadas.

## Quando usar

Arquivar, exportar, atribuir — na tabela, não no dropdown de uma linha.

  do="Contagem + uma ação primária. Some quando a seleção zera."
